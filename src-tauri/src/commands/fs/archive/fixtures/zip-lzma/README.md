# Independent ZIP-LZMA fixtures

`python-eos.zip` was generated by CPython 3.14.6 `zipfile.ZIP_LZMA` and contains
40 KiB of byte values, an empty member and a 9 MiB high-expansion member. The
archive sets the EOS flag and uses Python's normal method-14 framing.

The two `liblzma-no-eos` fixtures were encoded by the standalone C program using
liblzma's LZMA1EXT encoder with `ext_flags = 0`, then wrapped in ZIP headers by
`generate.py`. They contain a short sentence and an empty member, respectively.
Python independently reads every fixture back and verifies its bytes.

The checked-in files are sufficient for Rust tests; Python, a C compiler and
liblzma development headers are needed only to regenerate them. Compile
`no_eos.c` against liblzma, then run `generate.py` with the resulting executable's
absolute path as its argument. The executable is not part of the application.
